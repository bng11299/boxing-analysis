# Commands: One-clip chain and demo overlays

Moved verbatim from the project rules' `## Commands` on 2026-10-22. Add new recipes here, not to the project rules.

One clip, every Phase 1 output: `python analyse_clip.py --video data/own/<clip>.mov --stance orthodox --device cuda:0 [--skip-ingest] [--rounds 0-180,240-420]` (chains ingest -> find -> classify -> report -> overlay through their `main()`s into `results/analyse/<clip>.*`; stages run in a staging folder and publish only if all pass; `--skip-ingest` reuses `<out-dir>/<clip>.pose.npz` only if it matches the video) · Chain tests: `python tests/test_analyse_clip.py` ·

Punches drawn on the footage (demo asset): `python render_punches.py --video data/own/<clip>.mov --pose results/ingest/<clip>.pose.npz --classified results/punches/<clip>.classified.csv` -> `results/ingest/<clip>.punches.overlay.mp4` (refuses a CSV changed since its `.classified.json`; own footage only, never participants) · Tests: `python tests/test_render_punches.py`

Two boxers, one report each (vault ADR-0016): `python analyse_clip.py --two-boxer --video <clip>.mp4 --tracks <clip>.tracks.npz --identity <clip>.identity.csv --stance-a orthodox --stance-b southpaw [--gate-result G.json] [--rounds ...]` (opt-in; the solo path is unchanged; identity is an INPUT: `<clip>.identity.csv` = one row per tracked-person segment `track_id,first_frame,last_frame,boxer` with boxer A / B / unsure, plus the sidecar `<clip>.identity.json` with the CSV's sha256, the method, its gate verdict pass / fail / ungated and the tracks file it was made from; write both with `boxingvi.boxers.write_identity`, from per-row names via `segments_from_row_names` or from the linker via `row_names_from_linking`; a recorded PASS needs `--gate-result`, the gate's JSON with `"PASS": true`; chains `boxer_punches.py` -> `<clip>.boxers.csv` / `.boxers.json` / `.unsure.csv` and `report_boxers.py` -> `<clip>.{A,B}.report.xlsx` / `.summary.txt`, whose first sentence warns when the identity failed its gate or has none; inputs under a participant folder keep every output under it) · On Olympic with the linker as identity: `python olympic_boxers.py --data data/olympic --tracks results/ingest/olympic` (-> `results/olympic_boxers.json`; identity error cannot be measured there, RESULTS note 9) · Tests: `python tests/test_boxers.py`

Punch combinations (vault ADR-0019; in every solo and per-boxer summary and a Combinations sheet): a combination is a run of one person's punches each within 1.0 s of the last, never across a round or an identity-segment edge; unnamed punches show as `?`. The reports read `results/combinations_gate.json` (`--combo-gate` to point elsewhere) only if it was measured with the same classifier, finder rule and gap; otherwise they say the combinations are unmeasured or that the check does not apply. Score the gate (`docs/gates/combinations.md`): run C8's `find_punches.py` + `classify_punches.py` for IMG_4406 and IMG_4395 into a fresh folder, then `python score_combinations.py --clip IMG_4406 --clip IMG_4395 --punches-dir <that folder> --labels-dir data/own --pose-dir results/ingest --classifier weights/classifier/stgcnpp-boxingvi-seed0.json --out results/combinations_gate.json` (RESULTS rows 12a-12c, C19) · Tests: `python tests/test_combos.py`

Summary layout (every report): any warning first, then "In short:" (pace; the commonest type only if the hand check did not warn and the type is named reliably; how combinations start only if the combination gate measured it and it held), "What the tool saw:" and "How much to trust it:"; a statement that failed a check is marked where it appears. Optional LLM narrator (own footage only; nothing calls a model): `python report_punches.py ... --prompt-out` writes `<clip>.narration-prompt.json` (`prompt_text`, or `system` + `user`; `may_leave_machine: false` when an input is participant data: local model only); save the model's JSON reply and run `python narration_check.py --prompt results/reports/<clip>.narration-prompt.json --draft reply.json` -> `<clip>.narrated.txt` only if every number comes from the facts each sentence cites, none is spelled out, no absolutes, no failed fact in the headline and any use of one is hedged; warnings and trust notes are placed verbatim by the tool · Tests: `python tests/test_narrate.py`
