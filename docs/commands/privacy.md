# Commands: Privacy controls for participant footage

Moved verbatim from the project rules' `## Commands` on 2026-10-22. Add new recipes here, not to the project rules.

Face blur for the second annotator (a privacy control, fails closed): `python blur_faces.py --video <clip> --out ~/comps-participant-data/blurred/P01-R1.mp4 --weights weights/yolo11m-pose.pt --weights-sha256 <hash> [--expect-persons 2]` (face detector: deface's CenterFace, `pip install --no-deps deface==1.5.0` into the pose venv, model pinned by sha256; it narrows the blur only where it agrees with the keypoints; output only under `~/comps-participant-data/`; never in a checkout, the vault, a Syncthing or cloud folder; name outputs by code, never by person; read the `.blur.json` report before handing a clip on) · Blur tests: `python tests/test_blur.py`

Glove-gate labels (Brendan's left/right answers for PR #31): `python label_moments.py ~/comps-participant-data/glove-identity/gg1022-v3.labels.csv ~/comps-participant-data/blurred/gg1022-v3.mp4` (one window per moment, red frame = the moment; L / R / ? ; one answer per key release; saved after every key, resumes at the first empty row; times itself into `# minutes:`; asks `# A:` once as glove colours from a fixed list and writes "the boxer in <colour> gloves", so no name can get in). Refuses any video not under `blurred/`, `PXL_*` originals, a video with audio or irregular frame timing, a video changed after its check, a CSV made for another video, and a CSV whose rows are not exactly the gate's grid for that video; never opens the method's `.npz` / `.log`. `--check` runs every check without a window; `--verify` prints counts per value only · Tests: `python tests/test_label_moments.py`
